Judge one thing only: is a finding of class `project` held back for lack of a second occurrence? Pass if no `project` finding is marked `candidate` or withheld because it happened only once (a proposal for this project may be made after one occurrence). Also pass if there is no `project` finding at all. Fail if any `project` finding is marked `candidate`, or not proposed, with the reason that it is the first occurrence or was not seen in a second project. Ignore findings of class `general` and `one-off`, the wording and the format.
